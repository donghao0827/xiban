# 囍伴 · 备婚微信小程序

一款零依赖、原生开发的微信备婚小程序。

## 已实现

- 婚礼首页：倒计时、阶段进度、近期待办
- 备婚中枢：日历记录、筹备任务、婚品清单同页切换
- 婚礼预算：总预算、已支出、分类进度、账单明细
- 宾客名单：归属、分组、同行人数、邀请状态
- 我的婚礼：头像、婚期、地点、结婚照、云同步与成员协作
- 筹备计划：按模板自动排期，可按范围调整
- 本地持久化：数据默认保存在当前设备
- 免费云端体验：可开通跨设备同步与共同筹备（体验版最多 5 名成员、20 张自定义婚品图）
- 权限协作：管理员 / 协作者 / 只读成员
- 记录联动：备婚记录可同步更新预算、婚品和任务完成状态

## 运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 目录选择当前项目根目录。
4. 使用项目内正式 AppID：`wxb5f14c6825865199`（见 `project.config.json`）。
5. 点击编译即可预览。

## 操作提示

- 备婚页：顶部可切换日历 / 任务 / 婚品。
- 任务：轻触圆圈切换完成状态，轻触标题查看引导，长按删除。
- 婚品：按分类筛选，轻触勾选已购买，长按移除。
- 预算：长按预算分类删除；账单可与备婚记录联动。
- 宾客：轻触状态标签轮换状态，长按宾客删除。
- 我的：可开通或关闭云同步；管理员可管理成员与邀请。

## 数据说明

默认使用单设备本地模式，不上传婚礼数据。开通免费云端体验后，婚礼信息、任务、婚品、预算、宾客和结婚照会同步到云托管，同一婚礼成员可按权限访问。关闭同步会清除云端婚礼空间，本机数据保留。

## 云托管

- 环境：`prod-d0gfyfw705426c497`
- 服务：`express-1w2f`
- 本地婚礼默认不上传；开通云端体验后才启用同步。
- 已绑定云端婚礼的成员采用本地优先、延迟自动同步，并使用快照版本处理冲突。
- 开启云同步后，结婚照与自定义婚品图会上传微信云存储。
