# 囍伴 · 备婚微信小程序

一款零依赖、原生开发的微信备婚小程序 MVP。

## 已实现

- 婚礼首页：倒计时、整体进度、预算与宾客概览
- 筹备任务：分类、负责人、日期、完成状态、添加与删除
- 备婚记录：在日历选中日期后“记一下”，记录事项、花费及关联任务
- 婚礼预算：总预算、已支出、分类进度、添加与删除
- 宾客名单：归属、分组、同行人数、邀请状态、添加与删除
- 我的婚礼：新人、日期、城市和场地设置
- 结婚照：保留原图与取景展示图；本地模式保存在设备，云端模式上传微信云存储
- 婚品清单：内置 42 项礼服、婚房、现场、喜糖礼金与接亲敬茶采购事项
- 婚品图片：官方婚品图从微信对象存储加载，用户自定义图片按数据模式保存
- 本地持久化：所有数据存储在微信小程序本地缓存
- 免费本地模式：无需账号或云服务，婚礼数据只保存在当前设备
- 云端协作模式：现有云端婚礼可通过邀请码加入；新购入口待微信支付接入后开放
- 云同步：通过微信云托管备份任务、婚品、预算、宾客、婚礼信息和照片
- 记录联动：婚品记录自动更新采购清单和预算支出，关联任务会自动完成

## 运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 目录选择当前项目根目录。
4. AppID 可先使用测试号；发布前将 `project.config.json` 中的 `appid` 替换为自己的小程序 AppID。
5. 点击编译即可预览。

## 操作提示

- 任务页：轻触圆圈切换完成状态，长按任务删除。
- 任务页切换到“婚品清单”：按分类筛选，轻触勾选已购买，长按移除。
- 预算页：长按预算分类删除。
- 宾客页：轻触状态标签轮换状态，长按宾客删除。
- 我的婚礼：上传、更换或重新取景结婚照；云端成员会同步原图和展示图。

## 数据说明

默认使用单设备本地数据。云端婚礼支持新郎、新娘和亲友按管理员、协作者、只读成员权限共同使用；云端付费创建入口需在微信支付接入后开放。

## 云托管

- 环境：`prod-d0gfyfw705426c497`
- 服务：`express-1w2f`
- 本地婚礼不会上传个人婚礼数据，且不能直接绕过付费权益开启云同步。
